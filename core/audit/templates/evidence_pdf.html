Demo signature disclosure. This PDF is signed using a self-signed X.509 certificate generated locally on the demo machine (deploy/demo_signer.p12). The signature is cryptographically valid and any byte-level edit after signing will invalidate it — but the certificate itself is not anchored in the CCA India trust chain. In production deployment, Praman binds to a CCA-licensed Class-3 Digital Signature Certificate via PKCS#11 (eMudhra ProxKey, ePass2003, or equivalent hardware token). The signature subject would then read as the issuing procurement officer's CCA-bound identity.
